Important — not a medical device

This tool is an undergraduate research prototype with no regulatory approval. It was trained exclusively on dermoscopic images captured through a contact dermatoscope. An ordinary smartphone photograph is an out-of-distribution input: the model will still return a confident-looking distribution, but that confidence is not meaningful. Never use this output to decide whether to seek care.

Interpretation

How the risk band is derived

The band is not a separate model output. It is a deterministic aggregation over the seven softmax probabilities: the malignant and pre-malignant categories — mel, bcc and akiec — are summed into a single score, and thresholded.

BandMalignant group totalIntended reading
Low< 0.20Distribution concentrated in benign categories. Not clearance.
Indeterminate0.20 – 0.50The model is not confident either way — the case a clinician would escalate rather than dismiss.
Elevated≥ 0.50Distribution dominated by malignant categories. A prompt to book an examination.

Melanoma probability is additionally surfaced on its own, because it is the project's primary endpoint and because a moderate melanoma probability is clinically more significant than the same probability mass sitting in the basal cell carcinoma class.

Thresholds are a deliberately conservative design choice rather than a calibrated clinical decision rule. They have not been validated against any outcome data, and should not be read as one.

Data handling

What happens to a submitted image

  • Downscaled before it leaves your device. The browser reduces the image to at most 1,024 pixels on its longest edge, and re-encodes it if it still exceeds 1 MB, before upload — the model only ever sees 224 × 224, so full-resolution transfer would be wasted bandwidth.
  • Held in memory only. The server decodes the upload into an array, runs inference, and discards it. Uploads are capped at 1 MB precisely so this holds: past that size the web framework would buffer the file to temporary storage, so anything larger is refused rather than written anywhere.
  • Not logged, not retained, not shared. No image, prediction, or derived feature is stored or transmitted onward.
  • Location never reaches the server. If you use the clinic finder, geolocation is read in the browser and used only to construct outbound map links.
