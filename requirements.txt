# nothing was installed at all and the function crashed importing fastapi.
#

# Vercel rejects any function over 500 MB. LiteRT only runs models, which is
# all this endpoint does, and installs in single-digit MB.
#
# Training and evaluation dependencies are in requirements-train.txt, and are
# deliberately not named requirements.txt so they never reach the function.
